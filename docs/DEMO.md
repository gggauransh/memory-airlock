# Three-minute demonstration

Use a fresh synthetic FalkorDB workspace. Enable local Ollama and select Live model agents. No payment card or API key is needed for this path. Keep configuration and credentials out of the recording.

## 0:00–0:25 — Problem and real inference

“When shared knowledge changes, old answers can survive across agent handoffs. Airlock previews the consequences, then refreshes the affected workflow.” Show FalkorDB connected and LOCAL AI. Explain that local inference is real; the server mandates the evidence reads.

## 0:25–0:55 — Two independent cases

Run returns-only for a 20-day purchase. Optionally choose the customer’s incorrect outside-window claim under the initial 30-day policy, and show the review correction. Run shipping-only for Germany. Show both cases current. Open a receipt to demonstrate the narrow evidence read.

## 0:55–1:30 — Change one policy

Review a 30-to-14-day refund update. Show the path from the refund fact to Atlas, Sage and Echo. Shipping is independent. Approve the change. These are current-policy checks, not historical purchase-entitlement decisions.

## 1:30–2:00 — Block stale reuse, refresh selectively

Return to Agent mission. The returns case says RECHECK; shipping stays CURRENT. Show disabled draft export. Click Refresh affected workflows. The corrected 20-day answer uses the 14-day window; shipping is not rerun. Reload to verify persistence.

## 2:00–2:30 — Missing knowledge also matters

Choose Expand shipping and review Germany as a new destination. The earlier shipping answer becomes affected through its policy scope even though no old shipping fact is retired. The return case stays current. Show preview without committing if short on time.

## 2:30–3:00 — Evidence and limits

Run comparison: 18 synthetic cases, chains/branches/shared consumers and missing knowledge. Explain that both full graph and in-memory traversals succeed. Direct-only and refresh-all illustrate dependency mistakes. Close with typed scope, local source-role limitations, model-prose limitations and AI-assistance disclosure.
